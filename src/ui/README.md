One component per workflow state plus the shared transport: `Grid` (Browse in both its views, grid thumbnails off a shared offscreen renderer and the rail at card scale), `Focus` (one preset expanded via Motion `layoutId`, with the Export sheet over it), `Transport` (play, pause, loop, scrub), and `ShaderPanel` (the DialKit panel: free dials, ramp, family, transport, all derived from the uniform manifest and written to the shader handle).
