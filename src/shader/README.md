The GPU side. `masses.ts` holds the one shader, `masses@1` (SPEC.md §2), as three passes: FIELD (a base colour, up to four soft masses composited in OKLab by mixing toward each mass weighted by its plateau falloff, darkest first; the depth stack in fixed order Curve, Parallax, Haze, Swirl, Relief, Grid, Shadow; the caption mask) into a half-float texture; BLUR, the Finish stage (motion blur with per-pixel jittered taps, or one direction of a separable Gaussian, each mixed by its intensity; run only when on, at half resolution for thumbnails and full for a focused card or export); FINAL (film grain peaking in the mids, static from the seed by default, the tonal clamp L 0.12..0.97, OKLab → sRGB with gamut mapping by chroma reduction). `massesManifest.ts` is the uniform table; `src/model/pack.ts` fills it from a card's draft, turning sizes in card widths into the shader's height units. `renderer.ts` is pure WebGL2 (context, three programs, one triangle, the pass chain, GPU timer); `stage.ts` is the one shared offscreen renderer every cell, the focused card and the export draw through, with the clock loop; `useStageHandle.ts` is the focused card's handle; `range.ts` measures a poster's L range for the Rail.

Editing the GLSL: Joe is usually looking at the live page, and a shader that fails to compile shows as an error card on every cell until the next save. Write the candidate source first (a scratch string, or the file with HMR paused), compile it headlessly before it lands (in the page: `const m = await import('/src/shader/masses.ts')`, then `compileShader` on a scratch `webgl2` context and read `getShaderInfoLog`), and make signature and call-site changes in one write, never two.

Motion is periodic by construction: every mass drifts on a circle with the loop phase plus a seeded offset, and the swirl's noise samples the same circle. Nothing reads raw time except the grain's frame index, and only when grain is animated.
