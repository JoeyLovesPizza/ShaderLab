Tracked preset files, schema 2 (SPEC.md §4; types in `src/model/types.ts`): one JSON per card, each a seed, the three modes the shuffle rolled, a base colour, one to four masses, texture, the depth stack, the caption switch and the loop, plus `family.json`, which holds the locks and bounds the shuffle respects and the family's defaults. Pretty-printed with sorted keys so diffs are one line per value. A file that fails validation loads as a flat grey card with its error under it rather than stopping the app. Finished presets are copied from the Export sheet's download into `Portfolio/public/shaders/`.
